# Ознаки ШІ-стилю в українському тексті — словник для scripts/ukr_ai_tells.py.
#
# Формат рядка: ключ | сила | шаблон | § | пояснення
#   сила:    strong — досить однієї появи;  medium — сигнал, якщо є ще щось;  weak — лише в купі з іншими
#   шаблон: регулярний вираз Python без урахування регістру. Межі слова додаються автоматично,
#            пробіл означає «будь-які пробіли». Альтернативи — через «|» БЕЗ пробілів довкола.
#            Апостроф пишіть як ['ʼ’] — тексти бувають з різними апострофами.
#   §: номер шаблону в SKILL.md
#
# Додаючи слово, перевір, чи воно не нормальне в цьому значенні (технічне «надійне зʼєднання» — ок).
# Окреме слово — не доказ. Скрипт рахує щільність, а рішення ухвалює людина чи агент.
