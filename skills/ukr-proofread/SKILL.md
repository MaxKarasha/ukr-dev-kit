# Вичитка українських текстів

Інструмент — `scripts/ukr_lint.py` (шлях відносно теки скіла; лише стандартний Python 3.9+).
Далі `L="python3 <тека скіла>/scripts/ukr_lint.py"`.

## Порядок роботи

1. **Знайди проблеми лінтером:**
   ```bash
   $L README.md docs/                  # файли й теки
   $L --diff origin/main               # лише рядки, змінені в гілці — для PR
   $L --staged                         # лише те, що в індексі — перед комітом
   $L -t "текст"                       # шматок тексту
   $L -v ...                           # з поясненням кожного правила
   ```
2. **Застосуй безпечні виправлення** (позначені ✎: лапки, тире, апостроф, пробіли, змішані алфавіти,
   разом/окремо за правописом): `$L --fix <файли>`. Перевір `git diff` після цього.
3. **Виправ решту сам, з урахуванням контексту.** Суржик і кальки лінтер лише підказує — правильна
   заміна залежить від відмінка й змісту: `являється лідером` → «є лідером», `прийміть участь` → «візьміть
   участь». Узгоджуй рід, число, відмінок; не міняй сенс.
4. **Вичитай очима те, чого правила не бачать** — див. `references/style-guide.md`: канцелярит, кальки
   зворотів, порядок слів, милозвучність, звертання на «ви», фемінітиви, однаковість термінів.
5. Ще раз `$L` — має бути чисто (або лише свідомі винятки).

## Рівні

- **помилка** — явна помилка (русизм, змішаний алфавіт, пробіл перед комою). Виправляй.
- **увага** — найімовірніше помилка, але залежить від контексту (`на протязі`: протяг — це ще й рух повітря в кімнаті).
- **порада** — стиль (`--level hint`, щоб побачити): милозвучність у/в, і/й, «3.5» → «3,5», канцелярит.

## Що вміє

- Формати: `.md .txt .rst`, `.json .arb`, `.yml .yaml`, `.po`, `.properties`, `.xml .html .vue .svelte`,
  рядки й коментарі в коді (JS/TS, Python, C#, Java, Kotlin, Swift, Dart, Go, PHP, Ruby…).
- У Markdown пропускає блоки коду, рядковий код і адреси посилань; усюди — URL, пошту, плейсхолдери
  (`{name}`, `{{count}}`, `%s`, `:attr`), HTML-теги.
- Російський текст (є `ы`/`э`/`ъ`/`ё` і немає і/ї/є/ґ) пропускає — це не помилка, а інша мова.
- `--format json` — для обробки; `--format github` — анотації в GitHub Actions.

## Налаштування проєкту — `.ukr-lint.json` у корені

```json
{
  "apostrophe": "’",
  "disable": ["euphony", "term/фіча"],
  "ignore": ["vendor/**", "*.min.js"],
  "allow": ["Дія", "Rozetka"],
  "levels": {"calque/з-точки-зору": "warning"}
}
```
- `apostrophe` — символ апострофа проєкту (типово `ʼ` U+02BC; часто обирають `’` U+2019).
- `disable` — правило, категорія (`surzhyk`, `calque`, `style`, `term`, `typography`, `alphabet`, `euphony`)
  або ключ правила. Вимкнути в тексті: `ukr-lint-disable-line`, `ukr-lint-disable-next-line`,
  блок між `ukr-lint-disable` … `ukr-lint-enable` (у будь-якому коментарі).

## Довідка

- `$L --rules [слово]` — список правил; `$L --explain calque/на-протязі` — пояснення.
- `references/style-guide.md` — що перевіряти очима (стиль, тон інтерфейсу, правопис 2019).
- `references/it-glossary.md` — українські ІТ-терміни: як перекладати branch, deploy, merge, issue…
- `references/typography.md` — лапки, тире, апостроф, числа, скорочення, нерозривні пробіли.
- Нове правило — один рядок у `rules/*.txt` (формат описано на початку файлу).
