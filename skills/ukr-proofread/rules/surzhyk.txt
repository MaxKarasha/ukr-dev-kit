# Суржик — російські слова й форми в українському тексті.
#
# Формат рядка:  ключ | рівень | шаблон | заміна | пояснення
#   рівень:  error — явна помилка;  warning — найімовірніше помилка;  hint — стилістична порада
#   шаблон:  регулярний вираз Python без урахування регістру. Межі слова додаються автоматично,
#            пробіл означає «будь-які пробіли». Альтернативи — через «|» БЕЗ пробілів довкола.
#   Апостроф у шаблоні пишіть як ['ʼ’] — тексти бувають з різними апострофами.
#
# Перед додаванням правила перевірте, чи слово не має законного українського значення
# (напр. «удалий» — «вдалий», «заказник» — природоохоронна територія). Для таких — точніший шаблон.
