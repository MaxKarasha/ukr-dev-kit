# HolosTTS — локальний рушій

[HolosTTS](https://github.com/patriotyk/HolosTTS) — відкрита модель української мови (автор — patriotyk,
ліцензія MIT): 24 кГц, кілька десятків голосів, автоматичні наголоси. Працює на CPU, без інтернету
після першого завантаження.

## Встановлення

```bash
python3 ukr_voice.py setup holos
```
- клонує HolosTTS у `~/.local/share/ukr-voice/HolosTTS` на **закріпленому коміті**;
- ставить оточення `~/.local/share/ukr-voice/venv` (torch тощо, ~2 ГБ) із закріпленими версіями;
- ваги з Hugging Face беруться **закріпленої ревізії** — оновлення ваг у репозиторії автора не зламає
  встановлення (саме так ламаються незакріплені установки: новий формат ваг не підходить до старого коду).

Повторний запуск нічого не перекачує. Інша тека — змінна `UKR_VOICE_HOME`.

## Голоси

```bash
python3 ukr_voice.py voices --engine holos
python3 ukr_voice.py audition "Фраза" -o picks/ --engine holos
```

- **Суміш голосів** `Speaker_A*0.5+Speaker_B*0.5` змішує манеру вимови й тембр без обробки звуку —
  найкращий спосіб отримати новий природний голос.
- **Тембр і манера окремо**: вектор голосу = 128 чисел тембру + 128 чисел просодії (паузи, ритм, інтонація).
  `timbre=Speaker_43*0.5+Speaker_37*0.5;prosody=Speaker_43` — тембр суміші, манера одного голосу.
  Подобається голос, але не паузи й темп — міняй `prosody`; подобається подача, але не тембр — `timbre`.

## Параметри

| Параметр | Діапазон | Що робить |
|---|---|---|
| `--speed` | 0.9–1.15 | темп самої моделі (не прискорюй ffmpeg-ом — звучить синтетично) |
| `--expr` | 1.0–1.35 | розмах інтонації; модель читає рівно, як диктор, тож персонажам 1.15–1.3 |
| `--pitch` | 0.85–1.15 | висота тону без «металу» (крива висоти міняється до синтезу) |
| `--full-stress` | — | наголос і на односкладових словах (типово знято — мова плавніша) |
| `--af` | — | додаткові фільтри ffmpeg |

## Відомі нюанси

- scipy закріплено на 1.13.1: новіші збірки не вантажаться на свіжих macOS.
- Перший запуск моделі в кожному виклику — 20–40 с. Тому багато фраз давай одним `batch`, а не серією `say`.
- Модель не читає цифр — пиши числа словами.
