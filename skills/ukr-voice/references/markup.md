# Режисерська розмітка

Модель сама не знає, що «Ого!» треба сказати із захватом, а перед розвʼязкою — витримати паузу. Позначки
в тексті не вимовляються, а керують подачею. Одна розмітка працює з обома рушіями.

## Позначки

| Позначка | HolosTTS | Gemini |
|---|---|---|
| `(радісно)` | розмах інтонації, висота, темп, гучність | опис подачі для частини тексту |
| `/` `//` `///` | пауза 0,12 / 0,3 / 0,5 с | `[short pause]` / `[pause]` / `[long pause]` |
| `[0.6]` | пауза рівно 0,6 с | найближча з трьох пауз |
| `*слово*` | повільніше, вище, гучніше | «stress the words: …» в описі подачі |
| `{тихо повільно: …}` | подача шматка | окрема частина з описом |
| `за+мок` | ручний наголос | знак наголосу U+0301 |
| `О~го` | протягнута голосна | ігнорується |

Емоції: `спокійно`, `радісно` (= `весело`), `захоплено`, `здивовано`, `обурено` (= `сердито`), `таємниче`
(= `пошепки`), `сумно`, `задумливо`, `гордо`, `налякано` (= `злякано`), `хитро`.
Подача шматка: `швидко`, `повільно`, `тихо`, `голосно`, `високо`, `низько`, `рівно`, `жваво` — можна поєднувати.

Невідоме слово в дужках, напр. «(див. нижче)», лишається звичайним текстом.

## Як розмічати, щоб звучало живо

- **Одна емоція на думку.** Не став емоцію на кожне слово — голос «стрибає». Зміна емоції всередині
  репліки — лише там, де персонаж справді перемикається: `(обурено) Не собак! / (радісно) *Котів*!`
- **Пауза — перед розвʼязкою чи жартом:** `Скану+ю… /// Це жира+ф!`. Пауза після звертання чи вставного
  слова — `/`. Довше 0,5 с у коротких відео не тримай.
- **Виділяй одне слово у фразі** — те, заради якого фразу кажуть: `Чому свиня *стоїть*?!`
- `?!`, `!`, `…` теж керують інтонацією — не прибирай їх.
- Зірочки — навколо **цілого** слова: `*Робот-боксер*`, а не `Робот-*боксер*`.
- Ручний наголос `+` працює разом з розміткою: `*хмарочо+с*`.

## Опис подачі для Gemini (`--style`)

Пиши англійською, коротко, через кому — прикметники й темп:

| Задача | Приклад |
|---|---|
| реклама | `bright, energetic, smiling, premium app commercial` |
| оповідач | `warm, natural narrator, clear diction, moderate pace` |
| казка | `gentle storyteller for children, slow, expressive` |
| новини | `confident news anchor, neutral, steady pace` |
| таємничо | `hushed, almost whispering, suspenseful pauses` |
| урок | `patient teacher, articulate, slightly slower` |

Опис застосовується до всього тексту; емоції з розмітки додаються до нього для своїх частин.
