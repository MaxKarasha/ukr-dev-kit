# Українська озвучка

Усе робить `scripts/ukr_voice.py` (шлях відносно теки цього скіла; лише стандартний Python 3.10+, для mp3 — ffmpeg).
Далі `UV="python3 <тека скіла>/scripts/ukr_voice.py"`.

## Перший крок — завжди `doctor`

```bash
$UV doctor
```
Показує, що готово: ffmpeg, ключ Gemini, HolosTTS, Whisper — і який рушій буде обрано.

| Рушій | Коли | Налаштування |
|---|---|---|
| **gemini** | є ключ — найкраща якість, емоції описом, діалоги одним запитом | користувач у **своєму** терміналі: `$UV setup gemini` (або змінна `GEMINI_API_KEY`) |
| **holos** | офлайн, приватні тексти, без лімітів | `$UV setup holos` — ~2 ГБ, кілька хвилин |

Не проси вставити ключ у чат: `setup gemini` читає його приховано в терміналі користувача
(команда з `!` у Claude Code не приймає введення — нехай відкриє звичайний термінал).
Текст для Gemini йде на сервери Google — для конфіденційних текстів пропонуй `--engine holos`.

## Озвучити

```bash
$UV say "Привіт! Це перевірка." -o out/hi.mp3                         # пресет «оповідач»
$UV say "Знижки до пʼятниці!" -o ad.mp3 --preset реклама
$UV say "Текст" -o a.mp3 --voice Kore --style "calm, slow, warm"         # Gemini: будь-який голос і подача
$UV say "Текст" -o a.wav --engine holos --voice Speaker_67 --expr 1.2   # локально
$UV presets          # оповідач, оповідач-ч, новини, реклама, реклама-ч, казка, урок, подкаст, подкаст-ч, гід
$UV voices           # 30 голосів Gemini з характером (★ — рекомендовані)
```

- Формат — за розширенням: `.mp3 .wav .ogg .m4a .flac`. Результат обрізано по тиші й вирівняно до −16 LUFS.
- `--style` (Gemini) — опис подачі **англійською**: «warm, smiling, slightly faster», «whispering, mysterious».
  Не пиши інструкцій у самому тексті — їх озвучить.
- Довгий текст можна давати цілком: його розріже по реченнях (до ~2500 символів на запит) і склеїть.
- Повтор того самого запиту береться з кешу (`~/.cache/ukr-voice`) — не платиш двічі. `--no-cache` — перегенерувати.

## Діалоги

```text
# scene.txt
Оля: (радісно) Тарасе, ти вже бачив новий реліз?
Тарас: Так, щойно оновив. / Працює *значно* швидше!
```
```bash
$UV dialog scene.txt -o scene.mp3                                  # ролі підбираються самі (за статтю імені)
$UV dialog scene.txt -o scene.mp3 --cast "Оля=Zephyr,Тарас=оповідач-ч"
$UV dialog scene.txt -o scene.mp3 --split lines/                   # + кожна репліка окремим файлом (для монтажу)
```
Gemini озвучує сцену одним запитом — голоси природно «чують» одне одного. З `--split` — по репліці.

## Режисерська розмітка (обидва рушії)

| Позначка | Що робить |
|---|---|
| `(радісно)` | емоція до кінця репліки чи до наступної: спокійно, радісно, захоплено, здивовано, обурено, таємниче, сумно, задумливо, гордо, налякано, хитро |
| `/` `//` `///`, `[0.6]` | пауза: коротка / середня / довга / у секундах |
| `*слово*` | логічний наголос фрази — одне слово на фразу |
| `{швидко: …}` | подача шматка: швидко, повільно, тихо, голосно, високо, низько, рівно, жваво |
| `за+мок` | ручний наголос: `+` після наголошеної голосної |
| `О~го` | протягнути голосну (лише HolosTTS) |

Правила живої подачі: одна емоція на думку; пауза — перед розвʼязкою чи жартом; виділяй одне слово.
Деталі й приклади — `references/markup.md`.

## Текст для озвучки

- Числа, дати, скорочення — **словами в потрібному відмінку**: «до пʼяти хвилин», «двадцять четвертого серпня»,
  «гривень», «ші» (ШІ). Gemini прочитає й цифри, але відмінок може схибити; HolosTTS цифр не читає.
- Латиницю й бренди — кирилицею, як вимовляють: «Ґуґл», «ютуб», «Айфон».
- Імена з незвичним наголосом додай у словник `~/.config/ukr-voice/lexicon.json`: `{"Ніко": "Ніко+"}` —
  він застосовується до кожного тексту обома рушіями.
- Субтитри роби з чистого тексту без розмітки.

## Підбір голосу

```bash
$UV audition "Вітаємо у нашому застосунку!" -o picks/ --gender f    # рекомендовані жіночі голоси Gemini
$UV audition "Фраза" -o picks/ --voices Kore,Sulafat,Aoede
$UV audition "Фраза" -o picks/ --engine holos                        # усі голоси HolosTTS
```
Сам ти слухати не можеш: віддай користувачу файли й назви варіанти. Обраний голос збережи пресетом у
`~/.config/ukr-voice/presets.json`: `{"мій-голос": {"note": "…", "gemini": {"voice": "Kore", "style": "…"}}}`.

## Перевірка результату

```bash
$UV check out/hi.mp3 --text "Привіт! Це перевірка."      # що почув Whisper і відсоток збігу
```
Збіг ≥ 85 % — добре. Нижче — перевір наголоси, числа, латиницю в тексті. Потрібен whisper.cpp
(`brew install whisper-cpp` + модель ggml-small.bin) — `doctor` підкаже.

## HolosTTS: тонке налаштування

`--speed` (1.0–1.15), `--expr` (жвавість 1.0–1.35), `--pitch` (0.85–1.15); суміші голосів
`Speaker_43*0.5+Speaker_37*0.5`; окремо тембр і манера `timbre=<суміш>;prosody=<суміш>`.
Модель живе лише під час синтезу — після озвучки памʼять вільна. `$UV status` / `$UV stop`.
Деталі — `references/holos.md`.

## Етика

Не клонуй і не імітуй голоси реальних людей без їхньої згоди. Синтезовану озвучку в рекламі та новинах
варто позначати як згенеровану.
