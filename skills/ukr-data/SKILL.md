# Українські дані

Інструмент — `scripts/ukr_data.py` (відносно теки скіла; стандартний Python 3.10+).
Далі `D="python3 <тека скіла>/scripts/ukr_data.py"`.

## Перевірити

```bash
$D check 3652504575                      # тип визначається сам
$D check UA213223130000026007233566001 14360570 "+38 (067) 123-45-67" --json
$D check 19900517-01234 --type unzr
```
Що показує: правильність, причину помилки (зокрема очікувану контрольну цифру) і розшифровку:
РНОКПП → дата народження й стать; IBAN → МФО, банк, формат; телефон → E.164, оператор; картка → система, маска.

| Тип | Формат | Контроль |
|---|---|---|
| `rnokpp` (ІПН) | 10 цифр | ваги −1, 5, 7, 9, 4, 6, 10, 5, 7; (сума mod 11) mod 10; перші 5 цифр — днів від 31.12.1899; 9-та — стать (непарна — чол.) |
| `edrpou` | 8 цифр | ваги 1…7 (або 7, 1…6 для кодів 30 000 000–60 000 000); mod 11; якщо 10 — ваги +2; знову 10 → 0 |
| `iban` | UA + 27 знаків | ISO 13616 mod 97 = 1; цифри 5–10 — МФО банку |
| `unzr` | РРРРММДД-ННННК | ваги 7, 3, 1 по колу; mod 10 (метод машинозчитуваної зони документів) |
| `phone` | +380 XX XXX XX XX | коди операторів |
| `card` | 13–19 цифр | алгоритм Луна |

## Згенерувати тестові дані

```bash
$D gen person -n 5 --json            # ПІБ (узгоджене по батькові), стать, дата, РНОКПП+УНЗР за датою, телефон, email, IBAN
$D gen rnokpp --sex f --birth 1990-05-17
$D gen company -n 3 --json           # ТОВ «…», ЄДРПОУ, IBAN, місто
$D gen iban --mfo 305299 -n 10       # IBAN конкретного банку
$D gen edrpou | unzr | phone | card
$D gen person -n 100 --seed 42 --json > seed.json     # відтворювано
```
Значення мають правильні контрольні суми, але **лише для тестів**: випадковий номер може збігтися зі
справжнім. Email — на зарезервованому домені `example.com`. Для фікстур давай `--seed`.

## Транслітерація (Постанова КМУ № 55 від 27.01.2010)

```bash
$D translit "Згорани, Юлія Щербак, Знамʼянка"    # Zghorany, Yuliia Shcherbak, Znamianka
$D translit --slug "Київ — столиця України!"     # kyiv-stolytsia-ukrainy
```
Правила: г → h, ґ → g, «зг» → zgh; є, ї, й, ю, я на початку слова → ye, yi, y, yu, ya, далі → ie, i, i, iu, ia;
ь і апостроф не передаються. Саме так пишуть імена в закордонних паспортах і банківських картках.

## Числа й суми прописом

```bash
$D amount 1234.56                       # Одна тисяча двісті тридцять чотири гривні 56 копійок
$D amount "21 000,01" --currency USD --kop-words
$D words 2021 --gender f                # дві тисячі двадцять одна (рід іменника після числа)
$D plural 24 файл файли файлів          # 24 файли
```
Гривня й копійка — жіночого роду («одна гривня», «дві копійки»), долар і цент — чоловічого, євро — середнього.
Суму приймає рядком, тож копійки не губляться на округленні.

## Додати перевірку у код проєкту

Не пиши алгоритми з памʼяті — бери перевірені реалізації з `references/validators.md`
(TypeScript, Python, C#: РНОКПП, ЄДРПОУ, IBAN, УНЗР, телефон, множина, транслітерація) і додай тести
з векторами звідти ж. Для форм: нормалізуй введення (пробіли, дефіси, `+38`) до перевірки й показуй
зрозуміле повідомлення («Неправильна контрольна цифра РНОКПП»), а не «Невірний формат».
