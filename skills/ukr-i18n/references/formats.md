# Формати для uk-UA

Головне правило: **форматуйте через `Intl` / ICU з локаллю `uk-UA`**, а не шаблонами рядків.
Значення нижче — фактичний результат `Intl` у Node 22.

## Числа й гроші

| Що | Результат | Код |
|---|---|---|
| Число | `1 234 567,891` | `new Intl.NumberFormat('uk-UA').format(1234567.891)` |
| Гроші | `1 234,56 ₴` | `new Intl.NumberFormat('uk-UA', {style: 'currency', currency: 'UAH'}).format(1234.56)` |
| Код валюти | `5,00 UAH` | `{style: 'currency', currency: 'UAH', currencyDisplay: 'code'}` |
| Відсотки | `50%` | `{style: 'percent'}` |

- Розділювач тисяч — **нерозривний пробіл** (U+00A0), тож тести на кшталт `expect(x).toBe('1 234')`
  падають. Порівнюйте з `'1 234'` або нормалізуйте пробіли.
- «грн» без крапки; у текстах — «100 грн», у цінниках — «100 ₴» (знак після суми).
- Сума прописом для рахунків — `ukr_data.py amount` (скіл ukr-data).

## Дати й час

| Що | Результат | Код |
|---|---|---|
| Коротко | `23.11.2026` | `new Intl.DateTimeFormat('uk-UA').format(d)` |
| Довго | `23 листопада 2026 р.` | `{dateStyle: 'long'}` |
| Повністю | `понеділок, 23 листопада 2026 р.` | `{dateStyle: 'full'}` |
| Час | `14:30` | `{timeStyle: 'short'}` — 24-годинний |
| Відносно | `3 дні тому`, `за 5 хвилин` | `new Intl.RelativeTimeFormat('uk', {numeric: 'auto'})` |

- Місяць після числа — **у родовому відмінку** («23 листопада»), окремо — у називному
  («листопад 2026»). Самописні масиви назв місяців майже завжди помиляються саме тут —
  `Intl` з `month: 'long'` у складі дати повертає правильну форму.
- Тиждень починається з **понеділка** (календарі, `firstDayOfWeek: 1`).
- Часовий пояс — `Europe/Kyiv` (стара назва `Europe/Kiev` — псевдонім у старих базах tz).

## Телефони

Формат: `+380 67 123 45 67`; зберігайте в E.164: `+380671234567`. Перевірка, оператор, нормалізація
`067…`/`38067…`/`+38 (067) …` — `ukr_data.py check` (скіл ukr-data).

## Адреси

```
вул. Хрещатик, 1, кв. 5
м. Київ, 01001
```
Поштовий індекс — 5 цифр. Порядок полів у формі: область → населений пункт → вулиця → будинок → квартира →
індекс. Для довідника населених пунктів — кодифікатор КАТОТТГ.

## Імена

- У документах — «Прізвище Імʼя По батькові» (по батькові необовʼязкове); в інтерфейсі — «Імʼя Прізвище».
- Окреме поле «По батькові» — необовʼязкове.
- **Кличний відмінок** у звертаннях: «Вітаємо, Олено!», «Тарасе», «Андрію», «пане Іване» — `ukr_data.py vocative`
  (скіл ukr-data). Якщо його не утворюєте — пишіть без звертання на імʼя («Вітаємо!»), а не «Вітаємо, Олена!».
- Латиницею (паспорт, картка, IBAN) — офіційна транслітерація: `ukr_data.py translit` (скіл ukr-data).
- Валідація: літери, апостроф (усі варіанти), дефіс, пробіл. Не обмежуйте `[а-я]` — там немає і, ї, є, ґ.

## Алфавіт, сортування, пошук

Абетка: а б в г ґ д е є ж з и і ї й к л м н о п р с т у ф х ц ч ш щ ь ю я (33 літери).

- **Сортування:** `Intl.Collator('uk')`, `array.sort(new Intl.Collator('uk').compare)`;
  PostgreSQL — ICU-колація `"uk-UA-x-icu"`; Python — `PyICU` або `locale.strxfrm` з `uk_UA.UTF-8`.
  Наївне сортування за кодами Unicode ставить «Ґ», «Є», «І», «Ї» після «я».
- **Регулярні вирази:** `[а-яА-Я]` не містить і, ї, є, ґ. Пишіть `[а-яіїєґА-ЯІЇЄҐʼ’'-]` або `\p{Script=Cyrillic}`.
- **Пошук:** нормалізуйте апостроф (`ʼ ’ ' ‘ \``→ один символ), регістр; за потреби — `ґ`→`г`.
- **Регістр:** `'і'.toUpperCase()` → `І` працює коректно; турецьких пасток з `i` немає, але латинська `i`
  в українському слові — частий баг (див. ukr-proofread, правило `alphabet/mixed`).

## Код мови й заголовки

- `uk` / `uk-UA` — у `<html lang="uk">`, `Accept-Language`, назвах файлів (`uk.json`, `values-uk`, `uk.lproj`).
- `ua` — домен і код країни, **не мова**. `ru-UA` — російська в Україні, не українська.
- Шрифти: перевірте, що шрифт має `ґ`, `є`, `ї`, `ʼ` та «ялинки» — інакше браузер підставить запасний.
