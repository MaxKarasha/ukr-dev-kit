# Українська локалізація

Перевіряльник — `scripts/i18n_check.py` (відносно теки скіла; стандартний Python 3.10+).
Далі `I="python3 <тека скіла>/scripts/i18n_check.py"`.

## Додати українську мову

1. **Код мови — `uk`, локаль — `uk-UA`.** Не `ua` (це код країни) і не `ru-UA`.
2. **Плюралізація** — українській потрібні форми `one`, `few`, `many` + `other` (дроби).
   Конфіг для свого фреймворку візьми з `references/plurals.md` — у vue-i18n і деяких інших
   бібліотеках правила для української треба задати вручну, інакше «5 файли».
3. **Переклад** — тексти інтерфейсу за `references/ui-glossary.md`: кнопки неозначеною формою
   («Зберегти»), інструкції на «ви» («Введіть пароль»), без родових пасток («Вхід виконано»).
   Плейсхолдери, теги й ключі — без змін.
4. **Формати** — дати, числа, гривня, телефон, адреса, сортування — `references/formats.md`.
   Використовуй `Intl`/ICU з локаллю `uk-UA`, а не ручні шаблони.
5. **Перевір:**
   ```bash
   $I --auto              # знайде всі українські локалі в проєкті й порівняє з англійськими
   $I --auto --lint       # + вичитка перекладів (суржик, типографіка) через ukr-proofread
   $I en.json uk.json     # конкретна пара
   $I uk.po               # gettext — сам по собі
   ```
   Виправ усі помилки; попередження переглянь.

## Що знаходить `i18n_check`

| Код | Що | Рівень |
|---|---|---|
| `missing` / `extra` | ключа немає в перекладі / ключ зайвий (застарів) | помилка / увага |
| `empty` | порожній переклад | помилка |
| `placeholder` | різні `{name}`, `{{count}}`, `%s`, `%1$d`, `:attr` | помилка |
| `plural` | неповні форми: i18next `_one/_few/_many/_other`, ICU, Android `quantity`, gettext `nplurals=3`, vue-i18n `\|` | помилка |
| `russian` | літери `ы`, `э`, `ъ`, `ё` — неперекладене з російської | помилка |
| `untranslated` | значення збігається з англійським | увага |
| `tags` | HTML-теги чи компоненти `<0>…</0>` відрізняються | увага |
| `locale-code` | файл чи тека з кодом `ua` | увага |

Формати: JSON/ARB, `.po`, Android `strings.xml`, iOS `.strings`, `.resx`, `.properties`, YAML (з PyYAML).
`--format github` — анотації в GitHub Actions; код виходу 1 при помилках.

## Перекладаючи

- Не перекладай ключі, плейсхолдери, назви брендів, код у бектиках.
- Довжина: український текст на 15–30 % довший за англійський — перевір кнопки й вузькі місця.
- Узгоджуй слова з числом через плюралізацію, а не «файл(ів)».
- Слова з апострофом: один символ на весь проєкт (див. ukr-proofread).
- Після перекладу — `--lint`: русизми на кшталт `настройки` трапляються навіть у машинних перекладах.

## Довідка

- `references/plurals.md` — налаштування множини для i18next, vue-i18n, ICU/FormatJS, Angular, Android,
  iOS, gettext, Flutter, .NET, Laravel, Rails, Java.
- `references/formats.md` — дати, час, числа, валюта, телефони, адреси, імена, сортування, пошук.
- `references/ui-glossary.md` — переклад типових рядків інтерфейсу.
- Для даних (РНОКПП, ЄДРПОУ, IBAN, транслітерація, сума прописом) — скіл ukr-data.
