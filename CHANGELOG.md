# Зміни

Формат — [Keep a Changelog](https://keepachangelog.com/uk/1.1.0/), версії — [SemVer](https://semver.org/lang/uk/).

## [0.4.0] — 2026-11-27

ukr-humanize перекалібровано за вимірами 2026 року: у нових моделей словникові штампи майже зникли,
а видають їх розмітка чату, тире й шаблон відповіді.

### Додано

- Сканер: розмітка Markdown у каналі, що її не показує (`--channel email|sms|instagram|facebook|linkedin|messenger|plain`),
  заглушки `[Імʼя]`, `[дата]`, тире-зʼєднувач «**Назва** — пояснення» (`label-dash`), частка речень з тире
  (`dash-rate`, поріг — кожне четверте), знаки оклику, рівні абзаци, «Чому обирають нас» і «Чекаємо на вас!»,
  прапорці важливості («і це важливо», «більше, ніж просто»).
- Ознаки людської чернетки (дефіс замість тире, латиниця в кириличних словах, різні апострофи) — окремим
  рядком: їх виправляють як типографіку, а не як ШІ.
- Скіл: таблиця вимірів, правила для кожного каналу, тире-зʼєднувачі за формою (правопис § 161),
  розділ «Чого не додавати ніколи», не більше двох кіл правок і підсумок перевірки, тест переносності,
  «недовиразність» української ШІ-прози для художнього тексту. Джерела — `references/sources.md`
  (panchlab/humanizer-uk, avoid-ai-writing, Shaib et al., Sun et al., Reinhart et al., UNLP 2026).
- Eval-кейс `humanize-email-markup`.

### Змінено

- Title Case — слабка ознака (у 2026 це частіше людська SEO-звичка); «Висновок» — сильна.
- Поріг рівної довжини речень — варіація < 0,45 (у людей ≈ 0,65).
- Окреме слабке слово зі словника без інших ознак не показується.
- Текст посилань `[текст](url)` більше не плутається із заглушками; HTML-рядки не аналізуються.

## [0.3.0] — 2026-11-27

### Додано

- **ukr-humanize** — прибирання ШІ-стилю з українських текстів. 26 шаблонів з українськими прикладами
  (адаптація [humanizer](https://github.com/blader/humanizer), MIT), українська специфіка: граматичне тире
  проти тире-звʼязки, «ялинки», дієприслівникові хвости, кальки на кшталт «може похвалитися».
  Шар для художнього тексту за дослідженням StoryScope (arXiv:2604.03136).
- Сканер `ukr-ai-tells`: 70+ словникових ознак (`rules/tells.txt`) і структурні звички — тире-звʼязки,
  Title Case і емодзі в заголовках, жирні мітки, однакові початки й рівна довжина речень, шаблонні розділи;
  щільність на 1000 слів, `--format json`, `--max-score` для CI. Команда `ukr-ai-tells` у пакеті PyPI.
- Тести сканера, зокрема на людському корпусі (щільність < 6), і eval-кейс `humanize-blog-post`.

## [0.2.0] — 2026-11-23

### Додано

- Пакет на PyPI: `pipx install ukr-dev-kit` дає команди `ukr-lint`, `ukr-i18n`, `ukr-data`, `ukr-voice`.
  Код команд — ті самі скрипти скілів, без дублювання.
- Автоматичний випуск на PyPI за тегом (Trusted Publishing) і перевірка збірки пакета в CI.
- `tools/bump_version.py` — версія змінюється одразу в маніфестах плагіна, пакеті й скриптах.
- **ukr-voice:** субтитри SRT/VTT — `say --subs`, `dialog --subs` (з іменами мовців), `subs` для готового аудіо;
  текст оригінальний, час — з Whisper за словами.
- **ukr-data:** кличний відмінок для звертань — `vocative "Олена Петрівна"` → «Олено Петрівно», `--formal` → «пані …».
- **Evals** для `claude plugin eval`: 7 кейсів, зокрема негативний; результати в `evals/RESULTS.md`.
- **Корпус грамотного тексту** (Конституція, статті Вікіпедії) — тест на відсутність хибних спрацювань.

### Змінено

- pre-commit хуки встановлюють пакет (`language: python`) — працюють і на Windows.
- Мінімальна версія Python — 3.10.
- **ukr-lint** точніший: не перевіряє речення російською й у дореформеній орфографії (цитати, бібліографія),
  не вимагає прибирати пробіл перед « : » і « ; » (бібліографічний стандарт ДСТУ 8302),
  «являє собою» — порада, а не помилка; виправлено хибне спрацювання на іменнику «відміна».

## [0.1.0] — 2026-11-23

Перший публічний випуск.

### Додано

- **ukr-voice** — озвучка через Gemini TTS і HolosTTS з автоматичним вибором рушія; 10 пресетів для обох
  рушіїв; режисерська розмітка (емоції, паузи, наголоси, подача шматків); діалоги кількома голосами одним
  запитом; прослуховування голосів; кеш; перевірка розбірливості через Whisper; `doctor` і `setup`.
  HolosTTS закріплено на версії коду й ревізії ваг, сумісних між собою.
- **ukr-proofread** — лінтер `ukr-lint`: 140+ правил (суржик, кальки, правопис 2019, терміни), типографіка,
  змішані алфавіти; Markdown, JSON, YAML, PO, HTML/Vue, рядки в коді; `--fix`, `--diff`, `--staged`;
  формати text, json, github; конфіг `.ukr-lint.json`; довідники зі стилю, типографіки й ІТ-термінології.
- **ukr-i18n** — `i18n_check`: порівняння локалей для i18next, vue-i18n, ICU, gettext, Android, iOS, .resx,
  .properties, YAML; плюралізація, плейсхолдери, неперекладене, код `ua`; довідники з множини для
  12 фреймворків, форматів uk-UA й перекладу інтерфейсу.
- **ukr-data** — перевірка й генерація РНОКПП, ЄДРПОУ, IBAN, УНЗР, телефонів, карток; тестові профілі
  людей і компаній; транслітерація КМУ № 55; числа й суми прописом; валідатори TypeScript, Python, C#.
- Плагін Claude Code з хуком автовичитки, pre-commit хуки, GitHub Action, CI на Linux, macOS і Windows.
