# Корпус грамотного тексту

Тест `tests/test_corpus.py` проганяє ukr-lint по цих текстах і вимагає **нуль помилок і попереджень**.
Це захист від хибних спрацювань: нове правило, що чіпляється до правильної української, одразу ламає CI.

Корпус охоплює різні стилі: юридичний, науковий, технічний, енциклопедичний, а також складні для
лінтера місця — бібліографію російською, давньоруські цитати, назви латиницею, числа й формули.

## Зміни відносно джерел

- Типографіка уніфікована командою `ukr_lint.py --fix`: апостроф `ʼ`, лапки «ялинки», тире «—», три крапки «…».

- Виправлено помилки, знайдені лінтером: «згідно рейтингу / повідомлення» → «згідно з рейтингом /
  повідомленням» (3), «не дивлячись на» → «незважаючи на», «Учбовий курс» → «Навчальний курс»,
  «По завершенню» → «Після завершення», «В першу чергу» → «Насамперед», «вводу-виводу» → «введення-виведення».

## Як додати текст

Додайте `.txt` з якісним сучасним текстом, вкажіть джерело й ліцензію в таблиці, запустіть
`python3 -m unittest tests.test_corpus` і виправте в копії справжні помилки (якщо лінтер знайшов
хибне спрацювання — виправте правило, а не текст).
